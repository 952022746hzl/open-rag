## 整体架构图

```
┌────────────────────────────────────────────────────────┐
│           前端（Next.js 15 + shadcn/ui）                │
│  登录 | 文档管理 | 可见范围配置 | 对话 | 历史会话        │
└──────────────────────┬─────────────────────────────────┘
                       │ HTTP + Authorization: Bearer <JWT>
┌──────────────────────▼─────────────────────────────────┐
│               后端（FastAPI + uvicorn）                  │
├────────────────────────────────────────────────────────┤
│ JWT 鉴权中间件（get_current_user 依赖注入）              │
├────────────────────────────────────────────────────────┤
│ API 层   auth | users | departments                     │
│          documents | search | chat | sessions           │
├────────────────────────────────────────────────────────┤
│ Service 层   auth_service | document_service            │
│              embedding_service | search_service         │
│              chat_service                               │
├────────────────────────────────────────────────────────┤
│ Repository 层   user_repo | document_repo               │
│                 session_repo | vector_repo | storage_repo│
└──────┬──────────────┬────────────────┬─────────────────┘
       │              │                │
       ▼              ▼                ▼
┌────────────┐ ┌────────────┐ ┌─────────────────┐
│ PostgreSQL │ │  Qdrant    │ │     MinIO        │
│ 用户/部门  │ │ 向量+payload│ │  文档原文存储    │
│ 文档元数据 │ │ 权限过滤    │ │  预签名下载      │
│ 问答历史   │ │            │ │                  │
└────────────┘ └────────────┘ └─────────────────┘

外部服务：
  ├── DeepSeek API  → 问答生成
  └── DashScope API → text-embedding-v3 向量生成
```
