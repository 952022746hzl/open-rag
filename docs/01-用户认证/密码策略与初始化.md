# 密码策略与初始化

> 所属模块：用户认证 | 来源章节：§3.4–3.5 | [← 返回主索引](../需求文档.md)

---

## 密码策略

- 加密算法：bcrypt，cost factor = 12
- 密码复杂度：长度 ≥ 8，包含字母和数字
- 忘记密码：MVP 阶段由管理员重置，不做邮件找回
- 默认 admin 账户**首次登录须强制修改密码**（需在 `users` 表增加 `is_first_login BOOLEAN DEFAULT TRUE` 字段；登录响应中携带 `"require_password_change": true` 信号，前端跳转修改密码页面）`[P1]`

---

## 初始化

系统首次启动时，通过环境变量或 `alembic` 数据初始化脚本创建一个默认 admin 账户：

```
INIT_ADMIN_USERNAME=admin
INIT_ADMIN_PASSWORD=（必须在 .env 中指定，不提供默认值）
```
