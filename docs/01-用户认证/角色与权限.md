# 角色与权限

> 所属模块：用户认证 | 来源章节：§3.1–3.2 | [← 返回主索引](../需求文档.md)

---

## 角色定义

系统设两个角色：

| 角色 | 标识 | 说明 |
|------|------|------|
| 管理员 | `admin` | 可管理所有用户、部门、文档（含他人文档）；可查看全量会话记录 |
| 普通成员 | `member` | 可上传/管理自己的文档；可检索有权限的文档；只能查看自己的会话 |

---

## 权限矩阵

| 操作 | member | admin |
|------|:------:|:-----:|
| 登录 / 刷新 Token | ✅ | ✅ |
| 上传文档 | ✅ | ✅ |
| 检索 / 问答（按可见范围过滤） | ✅ | ✅ |
| 删除 / 修改**自己**上传的文档 | ✅ | ✅ |
| 删除 / 修改**他人**上传的文档 | ❌ | ✅ |
| 查看**自己**的会话历史 | ✅ | ✅ |
| 查看**所有人**的会话历史 | ❌ | ✅ |
| 创建 / 禁用用户 | ❌ | ✅ |
| 创建 / 管理部门 | ❌ | ✅ |
