## 认证要求

所有接口（除 `/auth/login`、`/auth/refresh` 外）均需携带：

```
Authorization: Bearer <access_token>
```

未携带或 Token 无效返回 `401 Unauthorized`，无权限操作返回 `403 Forbidden`。

## 错误响应格式

**标准错误响应**（FastAPI 标准）：

```json
{
  "detail": "错误描述"
}
```

| HTTP 状态码 | 含义 | 典型场景 |
|------------|------|---------|
| 400 | Bad Request | 参数校验失败、不支持的文件类型 |
| 401 | Unauthorized | Token 缺失、过期或签名无效 |
| 403 | Forbidden | 有效 Token 但无操作权限（如操作他人文档） |
| 404 | Not Found | 文档/会话/用户不存在 |
| 413 | Payload Too Large | 上传文件超过大小限制 |
| 422 | Unprocessable Entity | 请求体 JSON 格式错误（FastAPI 自动返回） |
| 500 | Internal Server Error | 服务内部异常 |
| 503 | Service Unavailable | 外部依赖不可达（MinIO / Qdrant / DeepSeek / DashScope） |

**422 验证错误响应体**（FastAPI 自动生成）：

```json
{
  "detail": [
    {
      "loc": ["body", "field_name"],
      "msg": "field required",
      "type": "value_error.missing"
    }
  ]
}
```
