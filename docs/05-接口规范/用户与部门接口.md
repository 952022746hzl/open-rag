# 用户与部门接口

> 所属模块：接口规范 | 来源章节：§11.2–11.3 | [← 返回主索引](../需求文档.md)

所有接口均为 **admin only**。

---

## 用户管理

### 创建用户

```
POST /api/v1/users
{
  "username":      "lisi",
  "display_name":  "李四",
  "password":      "Init@1234",
  "department_id": 3,
  "role":          "member"
}

Response 201:
{
  "id":            43,
  "username":      "lisi",
  "display_name":  "李四",
  "department_id": 3,
  "role":          "member",
  "is_active":     true
}
```

### 用户列表

```
GET /api/v1/users?limit=20&offset=0

Response 200:
{
  "items": [...],
  "total": 15
}
```

### 修改用户（角色、部门、启用/禁用）

```
PATCH /api/v1/users/{user_id}
{
  "role":          "admin",    // 可选
  "department_id": 4,          // 可选
  "is_active":     false       // 可选，禁用账户
}

Response 200: 更新后的用户对象
```

### 重置密码

```
POST /api/v1/users/{user_id}/reset-password
{
  "new_password": "NewPass@456"
}

Response 204
```

## 部门管理

```
GET  /api/v1/departments              → 部门列表
POST /api/v1/departments { "name": "质检部" }  → 创建部门，返回 201
```
