# 认证接口

> 所属模块：接口规范 | 来源章节：§11.1 | [← 返回主索引](../需求文档.md)

---

## 登录

```
POST /api/v1/auth/login
{
  "username": "zhangsan",
  "password": "abc12345"
}

Response 200:
{
  "access_token":  "eyJ...",
  "token_type":    "bearer",
  "expires_in":    7200,
  "user": {
    "id":              42,
    "username":        "zhangsan",
    "display_name":    "张三",
    "department_id":   3,
    "department_name": "焊接车间",
    "role":            "member"
  }
}
// refresh_token 通过 HttpOnly Cookie 写入
```

---

## 刷新 Token

```
POST /api/v1/auth/refresh
// refresh_token 从 HttpOnly Cookie 读取，无需请求体

Response 200:
{
  "access_token": "eyJ...",
  "expires_in":   7200
}
```

---

## 登出

```
POST /api/v1/auth/logout
// 服务端将当前 refresh_token 标记为已失效

Response 204
```

---

## 获取当前用户信息

```
GET /api/v1/auth/me

Response 200:
{
  "id":              42,
  "username":        "zhangsan",
  "display_name":    "张三",
  "department_id":   3,
  "department_name": "焊接车间",
  "role":            "member",
  "created_at":      "2026-05-01T09:00:00Z"
}
```
