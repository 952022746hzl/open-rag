## 上传文档

```
POST /api/v1/documents
Authorization: Bearer <token>
Content-Type: multipart/form-data

字段：
  file        File    必填  支持 pdf/docx/xlsx/pptx/txt/md，单文件上限 [待确认: 建议 50MB]，超出返回 413
  visibility  string  必填  public / department / private
  tags        string  可选  逗号分隔，如 "质量标准,焊接"

// uploader_id 和 department_id 由服务端从 JWT 提取，前端无需传

Response 201:
{
  "id":           1,
  "file_name":    "作业指导_焊接.pdf",
  "file_type":    "pdf",
  "uploader_id":  42,
  "department_id":3,
  "visibility":   "department",
  "tags":         ["质量标准", "焊接"],
  "file_size":    52428,
  "status":       "completed",
  "upload_time":  "2026-05-13T10:30:00Z"
}
```

## 文档列表

```
GET /api/v1/documents?limit=20&offset=0&file_type=pdf&tag=质量标准

// 服务端自动按当前用户的可见范围过滤，无需前端传 viewer 参数

Response 200:
{
  "items": [...],
  "total": 45
}
```

## 获取下载链接

```
GET /api/v1/documents/{document_id}/download

// 服务端校验当前用户是否有权访问该文档（基于 JWT）

Response 200:
{
  "download_url": "https://minio.../...?X-Amz-Signature=...",
  "expires_in":   3600
}
```

---

## 更新文档元数据

```
PATCH /api/v1/documents/{document_id}
{
  "visibility": "public",   // 可选
  "tags":       ["新标签"]  // 可选
}

// member 只能修改自己上传的文档；admin 可修改任意文档
// visibility 改变时需同步更新 Qdrant payload

Response 200: 更新后的文档对象
```

---

## 删除文档

```
DELETE /api/v1/documents/{document_id}

// member 只能删除自己上传的文档；admin 可删除任意文档
// 同步删除：PostgreSQL 记录 + Qdrant 向量点 + MinIO 对象

Response 204
```
