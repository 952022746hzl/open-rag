## 语义检索

```
POST /api/v1/search
{
  "query":           "如何进行焊接质量检查？",
  "top_k":           5,
  "score_threshold": 0.6,

  "filter": {
    "file_types":       ["pdf", "docx"],
    "uploader_ids":     [3, 7],
    "department_ids":   [2],
    "tags":             ["质量标准"],
    "upload_date_from": "2026-01-01",
    "upload_date_to":   "2026-05-13",
    "document_ids":     [1, 2, 3]
  }
}

Response 200:
{
  "results": [
    {
      "chunk_id":       456,
      "document_id":    123,
      "document_name":  "作业指导_焊接.pdf",
      "file_type":      "pdf",
      "uploader_id":    42,
      "tags":           ["质量标准", "焊接"],
      "source_location":"第 3 页",
      "snippet":        "焊接质量检查包括以下步骤...",
      "score":          0.87,
      "download_url":   "https://minio...（预签名，1h 有效）"
    }
  ],
  "total": 3
}
```

## 多轮问答

- `session_id` 传 `null` 时，服务端自动创建新会话并在响应中返回 `session_id`；后续轮次须携带上一轮返回的 `session_id` 以维持会话连续性。
- `top_k` 默认 5，`score_threshold` 默认 0.6，均可在请求中覆盖。

```
POST /api/v1/chat
{
  "session_id":      null,
  "question":        "具体怎么检查缺陷？",
  "top_k":           5,
  "score_threshold": 0.6,
  "filter":          { ... }
}

// 检索时自动按 JWT 中的身份做可见范围过滤

Response 200:
{
  "session_id": "sess_abc123xyz",
  "turn_id":    2,
  "question":   "具体怎么检查缺陷？",
  "answer":     "基于之前提到的内部缺陷检查，具体步骤是：\n1. 使用超声波检测...",
  "citations": [
    {
      "chunk_id":       789,
      "document_id":    123,
      "document_name":  "作业指导_焊接.pdf",
      "source_location":"第 3 页",
      "snippet":        "内部缺陷检查需要使用超声波检测...",
      "download_url":   "https://minio...（预签名）"
    }
  ],
  "timestamp": "2026-05-13T11:05:00Z"
}
```

## 会话列表

```
GET /api/v1/sessions?limit=20&offset=0

// member：只返回自己的会话
// admin：返回所有用户的会话（可加 &user_id=42 过滤）

Response 200:
{
  "sessions": [
    {
      "session_id":     "sess_abc123xyz",
      "user_id":        42,
      "turn_count":     3,
      "first_question": "焊接有哪些质量标准？",
      "last_active_at": "2026-05-13T11:15:00Z",
      "created_at":     "2026-05-13T11:00:00Z"
    }
  ],
  "total": 12
}
```

## 会话历史回放

```
GET /api/v1/sessions/{session_id}/history

// member 只能查看自己的会话；admin 可查看任意会话

Response 200:
{
  "session_id": "sess_abc123xyz",
  "turn_count": 3,
  "conversation": [
    {
      "turn_id":   1,
      "question":  "焊接有哪些质量标准？",
      "answer":    "...",
      "citations": [...],
      "timestamp": "2026-05-13T11:00:00Z"
    }
  ]
}
```
